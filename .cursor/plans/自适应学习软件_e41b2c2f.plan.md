# 自适应学习软件 — 完整架构计划

## 技术栈

- **框架**: Next.js 15 (App Router) + TypeScript
- **UI**: Tailwind CSS + shadcn/ui
- **AI（默认）**: DeepSeek API（`deepseek-chat` 文字/分析/路径分解），通过 OpenAI SDK 兼容层接入
- **AI（多模型预留接口）**: `lib/ai/provider.ts` 统一抽象，可无缝切换 OpenAI / Claude / Gemini 等
- **图像生成**: 预留接口，初期跳过或接入 Stability AI（DeepSeek 暂不支持图像生成）
- **数据库**: SQLite + Prisma ORM
- **状态管理**: Zustand
- **动画/3D**: Framer Motion + Three.js (用于 3D 动画内容)
- **包管理**: pnpm

## 数据库 Schema

```prisma
model LearningGoal {
  id          String   @id @default(cuid())
  title       String
  description String?
  clarification String?        // AI 梳理的需求分析
  nodes       LearningNode[]
  createdAt   DateTime @default(now())
}

model LearningNode {
  id          String   @id @default(cuid())
  goalId      String
  goal        LearningGoal @relation(fields: [goalId], references: [id])
  parentId    String?
  parent      LearningNode? @relation("NodeTree", fields: [parentId], references: [id])
  children    LearningNode[] @relation("NodeTree")
  title       String
  description String?
  isLeaf      Boolean  @default(false)  // 是否为原子节点（学习终点）
  order       Int      @default(0)
  status      NodeStatus @default(PENDING)
  content     LearningContent?
  reviews     ReviewRecord[]
  learnedAt   DateTime?
  nextReviewAt DateTime?
}

model LearningContent {
  id        String   @id @default(cuid())
  nodeId    String   @unique
  node      LearningNode @relation(fields: [nodeId], references: [id])
  type      ContentType  // TEXT / SLIDES / IMAGE_TEXT / THREE_D
  data      Json          // 存储生成的内容结构
}

model ReviewRecord {
  id         String   @id @default(cuid())
  nodeId     String
  node       LearningNode @relation(fields: [nodeId], references: [id])
  reviewNum  Int           // 第几次复习（1~6）
  dueAt      DateTime
  completedAt DateTime?
  score      Int?          // 复习测试得分
}

enum NodeStatus { PENDING IN_PROGRESS COMPLETED }
enum ContentType { TEXT SLIDES IMAGE_TEXT THREE_D }
```

## 四大模块详细设计

### 1. 目标梳理模块

- 用户在 `/goals/new` 页输入学习目标（如"AI 新时代程序员转型"）
- 前端发起对话流：AI 以 3-5 个追问问题（当前水平？学习时长？具体场景？）帮助澄清需求
- 确认后生成结构化的 `clarification` JSON 存入数据库
- UI：左侧输入对话，右侧实时预览需求摘要

### 2. 路径分解模块

**分解停止标准**（LLM Prompt 中注入的判断规则）：
- 节点是单一知识概念（如"什么是 REST API"）
- 节点是一个具体可操作步骤（如"用 Cursor 写一个接口"）
- 节点预估学习时间 ≤ 30 分钟
- 节点已无有意义的子主题

**分解流程**：
```
目标 → Level 1（6大方向）→ Level 2（每方向3-5模块）→ Level 3（原子叶节点）
```

- UI：交互式树状图（类 mind-map），可折叠展开
- 每个节点显示学习状态色（待学/进行中/完成）
- 支持手动添加/删除节点

### 3. 学习执行模块

用户点击叶节点 → 进入 `/learn/[nodeId]`，AI 按节点主题生成内容：

| 内容类型 | 触发场景 | 实现 |
|---------|---------|------|
| 纯文字 | 概念解释 | DeepSeek `deepseek-chat` streaming |
| 图文 | 流程/架构 | 文字（DeepSeek）+ 图像（预留，初期 AI 描述代替） |
| Slides | 系统性知识 | DeepSeek 生成多页 HTML/JSON Slides 结构 |
| 3D 动画 | 空间/可视化概念 | Three.js 场景 + DeepSeek 描述驱动 |

- 内容首次生成后缓存到 `LearningContent` 表，不重复调用 AI
- 学习完成点击"已掌握"→ 更新状态，触发艾宾浩斯计划写入

### 4. 复习模块

**艾宾浩斯曲线复习间隔**：
```
第1次: 学完后 1 天
第2次: 3 天后
第3次: 7 天后
第4次: 14 天后
第5次: 30 天后
第6次: 60 天后
```

- `/review` 页展示今日待复习节点卡片
- 复习形式：AI 生成 3 道测试题（选择/填空）+ 简短回顾
- 答题后记录得分，低于 60 分则缩短下次复习间隔
